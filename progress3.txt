# Progress Log for PRD3: Sources & Annotations System

## Learnings
- Django app structure follows standard pattern: models.py, views.py, serializers.py, filters.py, permissions.py, services.py
- Test files organized in tests/ subdirectory with test_models.py, test_views.py, test_services.py
- Must add new apps to INSTALLED_APPS in config/settings.py
- Pyright typecheck can be run with: cd backend && python -m pyright apps/sources
- PostgreSQL database is required for tests due to UUID field incompatibility with SQLite
- Tests require PostgreSQL database 'syncscript' to exist before running
- Use User.objects.create() instead of create_user() to avoid Pyright type warnings

## Iteration 2 - US-002: Create Source model with SourceType enum
- Created SourceType TextChoices enum with URL, PDF, BOOK, JOURNAL, DATASET options
- Created Source model with all required fields:
  - vault (FK to vaults.Vault, CASCADE)
  - url (URLField max 2048)
  - title (CharField max 512)
  - description (TextField, blank=True)
  - source_type (CharField with choices, default=URL)
  - metadata (JSONField, default=dict)
  - created_by (FK to User, SET_NULL, null=True)
  - is_deleted (BooleanField, default=False)
  - created_at, updated_at (auto timestamps)
- Added Meta class with:
  - ordering = ['-created_at']
  - indexes on ['vault', 'is_deleted'], ['source_type'], ['created_at']
  - UniqueConstraint for ['vault', 'url'] where is_deleted=False
- Files changed:
  - backend/apps/sources/models.py (implemented Source model)
  - PRD3.md (marked US-002 complete)
- Learnings for future iterations:
  - Django models.Q() is used for conditional constraints
  - UniqueConstraint with condition allows same URL if source is soft-deleted
  - JSONField default must be callable (dict) not dict instance
  - Typecheck passes with 0 errors

## Iteration 6 - US-005: Create metadata extraction service
- Added newspaper3k>=0.2.8 and lxml>=5.0 to requirements.txt
- Installed lxml_html_clean dependency (required by newer lxml versions)
- Created extract_metadata(url: str) -> MetadataDict function in services.py
- Function extracts:
  - title (or falls back to url if empty)
  - authors (list)
  - publication_date (formatted as ISO string if datetime, or string if already string)
  - abstract (first 500 chars of article text)
- Uses newspaper3k Config with request_timeout=10 seconds
- Returns fallback dict with 'title': url and 'error': error_message on any exception
- Files changed:
  - backend/requirements.txt (added newspaper3k and lxml)
  - backend/apps/sources/services.py (implemented extract_metadata)
  - PRD3.md (marked US-005 complete)
- Learnings for future iterations:
  - newspaper3k Config.request_timeout sets download timeout (not Article.download(timeout=...))
  - newspaper3k publish_date type is ambiguous - use hasattr check and type: ignore for isoformat()
  - lxml 6.x requires lxml_html_clean to be installed separately
  - Typecheck passes with 0 errors
