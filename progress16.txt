# Progress Log - PRD 16: Landing Page & Marketing Site

## Learnings
(Patterns discovered during implementation)

- Marketing route group files were previously created at `(marketing)/layout.tsx` and `(marketing)/page.tsx`
- Removed conflicting root `app/page.tsx` (backed up as `page.tsx.backup`) to allow marketing page to be the landing page
- Next.js route groups in parentheses `()` don't affect URL paths - files in `(marketing)/page.tsx` serve at `/`
- When multiple page.tsx files target the same route, the one outside the route group takes precedence
