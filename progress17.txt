# Progress Log - PRD 17: User Dashboard & Analytics

## Learnings
(Patterns discovered during implementation)

- Annotation model has custom save() that calls full_clean() - use bulk_create() in tests to bypass validation
- Test database needs to be migrated before running tests (use --keepdb flag to preserve database)
- When testing with timestamps, use QuerySet.update() to bypass model validation
