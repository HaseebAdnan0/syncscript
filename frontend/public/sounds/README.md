# Notification Sound

## Required File

Place a notification sound file at: `notification.mp3`

## Requirements

- **Format:** MP3 (best browser compatibility)
- **Size:** Under 50KB
- **Duration:** 0.5-1.5 seconds recommended
- **Type:** Short, pleasant notification beep/chime

## Free Sound Sources

You can download free notification sounds from:

1. **Freesound.org** - https://freesound.org/search/?q=notification
2. **Zapsplat** - https://www.zapsplat.com/sound-effect-category/notifications/
3. **Mixkit** - https://mixkit.co/free-sound-effects/notification/

## Example Sound

Search for terms like:
- "notification beep"
- "message tone"
- "subtle ping"
- "alert chime"

Choose a sound that is:
- Short and crisp
- Not too loud or jarring
- Professional sounding
- Pleasant to hear repeatedly

## Installation

1. Download your chosen notification sound
2. Convert to MP3 if needed (using online converter or ffmpeg)
3. Rename to `notification.mp3`
4. Place in this directory (`frontend/public/sounds/`)

The app will automatically use this sound when notifications appear (if enabled in user preferences).
