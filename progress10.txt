## Iteration 3 - US-003: Create useRealtimeUpdates hook
- Implemented optimistic updates hook at `frontend/src/hooks/useRealtimeUpdates.ts`
- Files changed:
  - Created `frontend/src/hooks/useRealtimeUpdates.ts`
  - Updated `PRD10.md` (marked US-003 complete)
- Learnings for future iterations:
  - Hook integrates with useVaultSocket via `addEventListener` (not `on`/`off`)
  - Uses `send(eventType, data)` signature (two params, not object)
  - Accepts options with vaultId, queryKey, optional mutation, and success/error event names
  - Returns `optimisticUpdate` function that accepts variables and optional optimistic data
  - Tracks pending updates with unique IDs (timestamp + random) for reconciliation
  - On success event: invalidates TanStack Query cache to fetch fresh server state
  - On error event: rolls back to previous cached state using stored snapshot
  - Uses refs to track pending updates Map to prevent stale closures
  - Cleanup on unmount clears all pending updates
  - Typecheck passes without issues

## Iteration 6 - US-006: Create usePresence hook
- Implemented presence tracking hook at `frontend/src/hooks/usePresence.ts`
- Files changed:
  - Created `frontend/src/hooks/usePresence.ts`
  - Updated `PRD10.md` (marked US-006 complete)
- Learnings for future iterations:
  - useVaultSocket returns `status` not `connectionStatus`
  - addEventListener returns cleanup function directly (no separate removeEventListener)
  - Hook accepts `{ vaultId: string, currentUserId?: number }` options
  - Returns: `{ activeMembers, activeMemberIds, isActive(userId), activeMembersCount }`
  - PresenceMember type: `{ userId, username, lastActivity: timestamp }`
  - Heartbeat sent every 30 seconds via `send('presence.heartbeat', { userId })`
  - Initial heartbeat sent immediately on connection
  - Event listeners for: `presence.join`, `presence.leave`, `presence.heartbeat`
  - Event data: `{ userId, username }` for join/heartbeat, `{ userId }` for leave
  - Inactive members removed after 60 seconds without heartbeat
  - Inactivity check runs every 10 seconds
  - Used Map<number, PresenceMember> for efficient member tracking
  - Cleanup functions stored for all event listeners and intervals
  - Typecheck passes without issues
