# Progress Log - PRD 15: AI Research Assistant

## Learnings
(Patterns discovered during implementation)

- User model requires both email AND username when creating test users (username is in REQUIRED_FIELDS)
- For type safety in tests, import User directly from apps.users.models rather than using get_user_model()
- Django datetime fields expect timezone-aware datetimes when USE_TZ=True
- Always check existing migrations before creating new ones to avoid conflicts

## Iteration 2 - US-002: Implement token usage tracking service
- Created apps/ai/services/ directory with __init__.py
- Implemented usage.py service with three core functions:
  - log_usage(user, request_type, tokens_used): Creates AIUsageLog records
  - get_daily_usage(user): Returns DailyUsage TypedDict with tokens_used and request_count for today
  - get_remaining_requests(user): Calculates remaining requests based on AI_DAILY_LIMIT setting
- Added AI_DAILY_LIMIT setting to config/settings.py (default: 20, configurable via env)
- Created comprehensive test suite in apps/ai/tests.py:
  - UsageTrackingTestCase with 7 tests covering all usage scenarios
  - Tests verify empty usage, usage with logs, old log filtering, and remaining request calculations
  - All tests pass successfully

Files changed:

- PRD15.md (marked US-002 complete)

Learnings for future iterations:
- TypedDict provides good type hints for return values without requiring full class definitions
- Django aggregation with Sum/Count returns None when no records exist, must handle with `or 0`
- max(0, remaining) pattern ensures we never return negative remaining requests
- Settings can be read with getattr(settings, 'KEY', default) for graceful fallback
- Test users need username because User.REQUIRED_FIELDS = ['username']
