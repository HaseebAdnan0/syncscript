## Iteration 2 - US-002: React Query hooks for vaults
- Created `frontend/src/hooks/useVaults.ts` with comprehensive React Query hooks:
  - useVaults(search?: string) - Fetches all vaults with optional search filtering
  - useVault(id) - Fetches single vault by ID
  - useCreateVault() - Creates new vault with automatic cache invalidation
  - useUpdateVault(id) - Updates vault and refreshes cache
  - useDeleteVault() - Deletes vault and removes from cache
  - useArchiveVault(id) - Archives vault (soft delete) with cache update
- Implemented query key factory pattern (vaultKeys) for organized cache management
- All mutations properly invalidate relevant queries on success
- useUpdateVault and useArchiveVault use setQueryData for optimistic updates
- Fixed pre-existing typecheck error in useAuth.ts (removed unused LoginCredentials interface)
- Typecheck passes successfully
